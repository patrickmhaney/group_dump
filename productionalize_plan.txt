DAY 1: CODE CLEANUP & SECURITY (12 TASKS)
================================================================================

CODE CLEANUP (5 tasks - estimated 4-6 hours):
□ Break main.py into modules (models, routes, auth, database)
□ Extract database models to separate models.py file
□ Create routes/ directory and split endpoints by domain:
  - auth.py (registration, login, token management)
  - groups.py (group CRUD, member management)
  - companies.py (company directory)
  - rentals.py (rental bookings)
□ Create config.py for environment variables and configuration
□ Remove unused migration scripts and organize directories

SECURITY FIXES (7 tasks - estimated 4-6 hours):
□ Generate and set proper SECRET_KEY (CRITICAL)
  - Use: python -c "import secrets; print(secrets.token_urlsafe(32))"
  - Never commit to git

□ Restrict CORS to groupdump.com domain only
  - Change from: allow_origins=["*"]
  - Change to: allow_origins=["https://groupdump.com", "https://www.groupdump.com"]

□ Add rate limiting to authentication endpoints
  - Install slowapi library
  - Limit login attempts: 5 per minute
  - Limit registration: 3 per hour

□ Audit for SQL injection vulnerabilities
  - Check all database queries
  - Ensure using SQLAlchemy ORM properly (no raw SQL)

□ Review Stripe webhook signature verification
  - Ensure webhook signatures are verified
  - Use stripe.Webhook.construct_event()

□ Add input validation and sanitization
  - Email validation
  - Password strength requirements
  - Sanitize user inputs (names, addresses)

□ Ensure sensitive data not logged
  - No passwords in logs
  - No API keys in logs
  - Redact sensitive fields
